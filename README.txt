永續福利箱 V3.1｜專題原型

開啟 index.html 即可預覽；order.html 是模擬訂購頁。
功能：六個內容分頁＋訂購專區導覽、預購進度示範、B2B2Hub 解說與採購試算、訂購與集中取貨、飲食偏好、訂購完成畫面、ESG 成本敏感度比較、食品批次履歷展示。

重要：所有預購進度與批次履歷為示範資料；不會建立真實訂單、不儲存個資、沒有付款。不要將 Github Pages 靜態表單誤當成正式訂單系統。

GitHub Pages：將資料夾內所有檔案上傳到既有 repository 根目錄（index.html 應在根目錄）。

本次修改：將網站「訂購試算」改為「訂購專區」，移除校園自取與校園教職員 Hub 選項；配送方式為企業／社區集中配送或低溫宅配。
